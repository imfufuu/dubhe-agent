# Dubhe Agent 功能与设置查询手册

## 页面与入口
- 导航页 `index.html`：产品入口；首屏按六条设计准则重排版（排版先行、物理动效、克制定色、线性图标、破格布局、细节较真），准则本身只作为系统提示词，不写进页面。
- 对话页 `app.html`：消息区、输入框、调节器、设置、沙箱面板、项目模式、模型选择器；`docs.html` 是文档与价目表。
- 首次进入会要求设置用户称谓（预设或自填），仅保存在本机浏览器。

## 模型与网关
- 设置 → 网关：TeamoRouter（默认）/ Anthropic / OpenAI / Gemini / DeepSeek / GLM / Grok / Kimi / 豆包 / Qwen / Cloudflare Workers AI / 自定义。每个网关独立保存 API Key、模型目录与基础 URL。
- 模型选择器只显示「热门」「低价」两种标签；Cloudflare Workers AI 不计价，账单以 Cloudflare 控制台为准。
- 生图模型按家族选择（GPT Image 2 / 2.5 / 2.6、Nano Banana、Midjourney、Cloudflare FLUX）；Cloudflare FLUX 只在 Cloudflare 网关出现。Midjourney 返回四宫格，应用自动切成 4 张。
- 识图 / 视频 / 音频模型在「多模态模型」里单独选择；标签描述定位（低价 / 通用 / 高精度 / 文档截图等），不表示能力等级。

## 调节器（独立页面）
- 回答温度：智能自调节、精确、严谨、均衡、创意；环境：Agent 模式（全部工具 + 系统提示词）或对话模式。
- **对话模式是纯净模型对话**：不上传任何 system/task/提示词，不声明工具能力，不传工具表；只把用户历史发给模型。UI 会隐藏沙箱、联网、快速、项目、面板按钮，思考按钮变成「思考打开/关闭」，附件仅文本类并直接解析进正文。
- 个性化系统提示词：独立补充层，不改变主提示词，对话模式下不发送。
- 自注册工具确认卡显示在对话输出里，不在调节器内；工具管理已合并到设置页「工具能力」栏目。

## 设置页
- 工具能力：本轮可用工具预览表 + 自注册工具（读取完整定义、启停、二次确认删除）。代码类工具必须先过静态安全初审，再由用户确认。
- 审核：关闭后普通对话与项目模式导入都不做本地审核；上游服务政策仍适用。
- 离线本地模型：导入 GGUF 到浏览器 OPFS，断网可用；上下文 8192，超出时自动裁剪历史。
- 网关访问令牌（可选）：只存 localStorage，不进会话导出；Workers AI 网关可启用 `GATEWAY_TOKEN` 与 `ALLOWED_ORIGINS`。
- 执行预算、思考强度、外观、临时缓存、版本信息等在同一页。

## 工具与产物
- 文件工具操作会话级虚拟文件系统；`internal/` 与 `uploads/` 始终保留。`write_file` 可写 `internal/`，只有 execute_javascript / execute_python 的沙箱回写通道禁止写 `internal/` 与 `.git/`。
- Agent 可用 `set_final_report` 指定一个非内部工作区文件，回合结束自动展开沙箱面板并打开。
- `:::choice` 单选、`:::choice multi 标题` 多选选择框；`:::chart` / `:::flow` / `:::mind` / Mermaid / DOT 用于结构化图。
- 旗帜语法 `::flag[us]::`，复制时 Unicode 内旗帜还原成 emoji，纯 PUA 设计复制为 `[flag]` 占位符。

## 设计准则（生成网页时默认执行）
排版先行 → 物理动效 → 克制定色 → 线性图标 → 破格布局 → 细节较真。对标作品站而非模板；深色不用纯黑，渐变不用彩虹，1px 发丝线与等宽数字是底线。
