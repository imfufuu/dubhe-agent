# Dubhe Agent 真实工作台录屏清单（V2 拍摄请求）

**用途：**为 16:9、约 25.6 秒的介绍片提供真实产品操作画面。只录实际 Dubhe Agent 页面和实际运行结果；不制作仿网页、不替换 UI 截图、不伪造模型响应或参数。片头/片尾 Logo 卡、字幕与剪辑包装可以后期制作，但工作台画面必须来自真实页面录屏。

## 请提供的素材

建议提供 **一段 45–60 秒的未剪辑录屏**，覆盖下面必拍镜头；如果更方便，也可以按镜头分别录成 4–5 个短文件。最终只取约 17–21 秒产品操作画面，其余时间给片头、卡点和片尾。

- 画面：1920×1080、16:9、30 fps；若设备方便可用 2560×1440。浏览器缩放 100%，工作台尽量铺满画面。
- 录制：原生屏幕录制，鼠标移动缓慢、有目的；不要录到桌面通知、浏览器开发者工具、个人目录路径或其他聊天内容。
- 不需要旁白、字幕、转场或后期变速；片中继续使用参考片原音轨，不把歌曲人声当解说，也不另加旁白。
- 不要在录屏中打开/展示 API Key，也不需要把 Key、GGUF 模型文件或个人文件夹发给我。可在自己的设备上使用本地模型后，只分享录屏。
- 如果系统文件选择器会显示私人路径，可录下点击「选择 GGUF 文件」后暂停，选完后再继续录；剪辑时只保留工作台里真实显示的模型信息，不露出路径。

## 内存告警备选镜头（非必拍）

如果你手头**已经有**一份实际会触发高风险的 GGUF，可以额外录 3–4 秒设置页的真实告警；如果没有，不要为了拍片下载或购买大模型，也不要用开发工具改 DOM 来制造告警。内存估算只是浏览器可用信息下的粗略工作集提示，不是可用 RAM 实测。

## 拍摄时请避免

- 不要用仿制 HTML、静态截图、PPT 或后期贴图替代真实工作台。
- 不要伪造模型名、参数量、量化方式、RAM 数值、生成答案、文件列表或完成状态。
- 不要写「100% 本地」「零云端泄漏」「绝不上传任何数据」之类超出单项 GGUF 文件/本地推理范围的保证。
- 不要把 `navigator.deviceMemory` 的粗略设备总内存说成剩余/可用内存。
- 不要让文件选择器暴露你的用户名、个人路径或私人文件名；模型本身不用交付。
- 不要录入或发给我 API Key，也不要在本次拍摄里调用网关模型。若本地模型不兼容工具调用，就只拍真实文本回答。
