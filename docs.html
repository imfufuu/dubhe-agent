SKILLS

同视频的三个 Gemini 模型及 file 请求格式；原音频上传网关，独立选择模型，用量缺失时明确标注。

CACHE

按哈希增量缓存

站内脚本预缓存，大依赖首次使用才加载。复用未变文件，新版本安全激活后清理本应用旧缓存。

NAVIGATION

留在当前页面

品牌图标回主页顶部，不再进入废除门页；中英文切换保持可视位置。

WORKSPACE

文件工作区更宽敞

宽屏 iPad 与电脑端停靠右侧面板，不再覆盖遮罩。打开文件后继续向左扩展；HTML/SVG 可切换代码、预览或并排查看。

MOTION

收放连贯，间距统一

工具、读写详情与附件菜单都有双向动画。黑白抛光从左向右扫过状态文案，工具名与路径保持静态；尊重减少动效设置。

AGENT

模型适配与可靠执行

按型号映射原生思考档位并保留分级验证降级；Python 按需加载依赖，编辑仅显示差异，导航演示可重播。

PREVIEW

静态预览默认隔离

HTML/SVG 预览禁用脚本与外网，支持嵌入本地样式和图片；需要交互运行时，仍通过明确的本地 Chromium 操作。

01我们如何处理数据（总览）

  • 本应用遵循「本地优先」：你的会话记录、设置、API Key、长效记忆、沙箱文件与附件保存于浏览器的 localStorage 与 IndexedDB，不会上传到作者或任何统计服务。
  • 作者不运营任何后端数据库，无法也无需存储或查看你的对话内容。

02本地存储技术说明

  • localStorage：轻量状态（设置、模型选择、会话骨架、API Key）。
  • IndexedDB：重数据（附件图片、沙箱生成图等大文件），与应用状态分开存放。
  • Cache Storage（Service Worker）：模型、审核资产与厂商图标的离线缓存，仅含静态资源，不含个人数据；可用 /system 通道 /cache clear 或浏览器设置清除。
  • 本应用不使用 Cookie 进行追踪，也不设置广告或分析类 Cookie。

03发送给第三方的数据

  • 你发送的消息与附件（含图片）会经 TeamoRouter 网关（api.teamorouter.com）转发给你所选模型的服务商用于生成回复；这是对话功能的必然传输。
  • API Key 仅作为网关鉴权凭证发送，不用于其他目的。
  • 称谓审核始终在本地浏览器完成，不会为审核发送给 Jev、网关或其他远程服务。启用内容审核时，普通对话文本先过本地规则；默认 TeamoRouter 网关下，未被本地规则拦截的审核文本（含文本附件摘录）还可能经网关发送到 Jev（System One），用于安全分类；选择其他网关时文本审核仅运行本地规则。文本随后是否发往所选模型提供商，取决于用户是否发送该消息。图片先由 NudeNet / NSFWJS 本地检查；若启用灰区远程复核，图片快照会发往当前配置的视觉审核路径。作者不接收这些审核内容；第三方接收者按其隐私政策处理。
  • 浏览器原生语音识别可能由浏览器厂商处理音频，不经过应用中继；不会自动发送识别结果。可选赞/踩保存在本地，仅作为下一轮模型请求的有限质量参考，不向作者上传统计。远程C++会发送源码/输入至godbolt.org，联网工具会发送指定URL或检索词至所选中继与上游。第三方服务商对所接收数据的处理受其各自隐私政策约束。

04我们不收集的信息

  • 不含统计分析、埋点、广告追踪、指纹采集或行为画像。仅在主动开始语音输入时请求麦克风权限、主动开启完成通知时请求通知权限；不请求地理位置或通讯录。
  • 不主动采集你的设备信息、IP 或使用时长；静态托管（GitHub Pages）侧的基础访问日志由其按自身政策处理，与作者无关。

05数据保留与安全

  • 本地数据保留至你主动清除（应用内「清空会话 / 清空记录」、浏览器清除站点数据、或卸载浏览器）。
  • API Key 仅在本地存储并仅向网关发送；请勿在共享设备上保存 Key。

06儿童隐私

  • 本应用面向一般用户，不面向 14 周岁以下儿童单独提供服务；如发现在无监护人同意下收集了儿童个人信息（本地存储），可通过下方联系方式要求清除。

07你的权利

  • 多选分享仅在本机生成长图或独立HTML文件，默认正文和附件，工具/思考可选；不会序列化应用设置与本机保存的Key，但选中内容本身可能含敏感信息，请分享前核对。通知固定超过60秒且后台才触发，手动停止不通知；通知内容不包含原始问题、代码、回答或文件路径。
  • 你对自己的本地数据享有完全控制权：随时查看、导出（/system 通道 /export）、更正或删除。
  • 因作者不持有你的数据，无需亦无法代为执行「删除请求」——删除即从你的浏览器彻底消失。
